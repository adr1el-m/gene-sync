About GeneSync

GeneSync is a bioinformatics learning tool for global pairwise sequence alignment. It compares two biological sequences, fills a dynamic programming matrix, traces the optimal path, and presents the final alignment with supporting interpretation.

Needleman-Wunsch DNA / RNA / Protein Browser Ready
⌬ System Flow
Phase 1 Ingestion and Validation

Input two sequences, clean FASTA-style text, normalize alphabet strings, and validate DNA, RNA, or protein symbols.

Phase 2 Algorithmic Execution

Initialize the scoring matrix, fill the DP grid, and record predecessor moves for traceback.

Phase 3 Analytics and Reporting

Compute identity, perform sequence-shuffling significance assessment, and map mutational hotspots.

Phase 4 UI and Presentation

Render matrix playback, aligned strings, diagnostics, hotspot graphs, history, and a printable browser report.

ƒ Algorithm Core

The Align tab applies the Needleman-Wunsch recurrence to every matrix cell:

F(i,j) = max(diagonal + substitution, up + gap, left + gap)

Diagonal represents a match or mismatch. Up and left represent gap insertion.

◇ Implemented Features
Input Validation

DNA, RNA, and protein alphabet checks with FASTA-style cleanup.

Global Alignment

Configurable match, mismatch, and gap scoring for pairwise alignment.

Matrix Traceback

Dynamic programming grid with the optimal traceback path highlighted.

Analytics

Identity percentage, shuffle significance, and sliding-window hotspot detection.

Output

Readable aligned-string view, local run history, and printable browser report.

Boundaries

Global pairwise alignment only, with a 5,000-character sequence cap and a 100,000-cell web-demo matrix cap.

⌕ Validation Sources

GeneSync uses a small curated marker database backed by these validation sources. Matched records become known variant results; unmatched differences remain candidates.
